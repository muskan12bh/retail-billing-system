 Retail Billing Management System

 Description

This project is a DBMS-based Retail Billing System developed using MariaDB. It manages customers, products, suppliers, orders, and payments efficiently.

 Database Structure

The system consists of 6 tables:

* Customers
* Products
* Suppliers
* Orders
* OrderDetails
* Payments

Features

* Normalized database (3NF)
* Foreign key relationships
* Indexing for performance optimization
* Triggers for:

  * Automatic stock update
  * Automatic total bill calculation

How to Run

1. Open MariaDB
2. Run:
   SOURCE retail_billing.sql;

Concepts Used

* ER Model
* Normalization
* Indexing (B+ Tree)
* File Organization (Heap)
* Triggers
